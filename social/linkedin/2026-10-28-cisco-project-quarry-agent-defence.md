A dangerous AI-agent workflow may look harmless one step at a time. That is the security gap Cisco’s open-source Project Quarry is designed to address.

Quarry provides a shared way to describe and detect harmful behaviour that emerges across a sequence of agent actions. This matters because conventional controls often inspect isolated API calls, tool invocations or prompts rather than the trajectory of an autonomous task.

For enterprise deployments, the lesson is clear:

- capture end-to-end agent telemetry;
- assess intent and cumulative impact, not only individual steps;
- align AI, cyber and operational-risk teams on a common threat model.

Agent governance will increasingly depend on runtime observability, not just pre-deployment testing.

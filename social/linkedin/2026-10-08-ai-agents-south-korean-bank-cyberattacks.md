AI-enabled cyber risk is no longer a hypothetical scenario for financial institutions.

Reuters reports that a suspected actor behind recent attacks on South Korean banks may have used both a Chinese-developed AI agent and Anthropic's Claude Code. Attribution is still developing, so the precise role of each tool should not be overstated.

The strategic message is already clear:

- general-purpose coding agents can accelerate reconnaissance and exploitation workflows;
- controls must cover tool permissions, credentials and execution environments, not only prompts;
- banks need red-team scenarios that assume attackers can orchestrate multiple AI tools.

Agent adoption and cyber resilience must be designed together.

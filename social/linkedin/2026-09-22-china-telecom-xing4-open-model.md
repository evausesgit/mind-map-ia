Open-weight agentic models are moving onto modest local hardware.

China Telecom AI’s Xing4.0-29B-A4B uses a mixture-of-experts architecture with 29 billion total parameters and four billion active per token. It offers a 256K context window, fits into a reported 15 GB runtime footprint, and scores 75 on SWE-bench Verified according to the company.

The release matters because local execution can change the enterprise trade-off:
- sensitive code and documents can remain on controlled infrastructure;
- inference costs become more predictable;
- model provenance and benchmark reproducibility still require validation.

Weights and code are distributed through GitHub and Hugging Face, expanding the practical open-model option set for agent workflows.

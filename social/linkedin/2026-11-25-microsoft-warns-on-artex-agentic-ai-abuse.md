Autonomous AI is changing the tempo of cyber defence—not just the tools attackers use.

Microsoft has published guidance on ARTEX, an agentic AI framework being abused by threat actors. The important point for enterprises is not one framework: it is the control gap created when software can plan, invoke tools and iterate at machine speed.

Security leaders should now be asking:
- Which identities and permissions can each agent use?
- Are tool calls and intermediate actions logged?
- Can the organization contain an agent without disrupting critical services?

Agent governance and cyber resilience are becoming the same operating problem.

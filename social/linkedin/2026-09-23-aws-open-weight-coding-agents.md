Open-weight models are moving from model catalogues into governed enterprise workflows.

AWS has published a reference setup connecting the open-source OpenCode agent to Kimi K3, GPT-OSS 120B and Nemotron 3 Super 120B through Amazon Bedrock. Teams can route planning and implementation to different models while retaining IAM, CloudTrail and regional processing controls.

The architecture is notable because it combines:
- model choice rather than single-provider lock-in;
- account-level security and auditability;
- a Flex tier priced 50% below Standard for latency-tolerant batch workloads.

For regulated organisations, the decision is no longer simply open versus proprietary. The more useful question is whether each model can operate inside a controlled, measurable and replaceable execution layer.

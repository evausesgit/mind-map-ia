AI coding is moving from generating code to deciding whether code is ready to merge.

Anthropic’s new Claude Ship combines code review with beta agents that can resolve CI failures and merge conflicts, then approve routine changes against policies stored in the repository.

The important enterprise question is not whether an agent can approve a pull request. It is how that authority is bounded:
- start in observe-only mode and compare decisions with human reviewers;
- define mandatory escalation paths for sensitive repositories and changes;
- retain the evidence, policy version and rollback path behind every approval.

As agent throughput rises, approval can become the next bottleneck. Removing it safely will require policy-as-code, auditable traces and clear human accountability—not just a stronger model.

A smaller model can be the better enterprise AI decision.

GitHub has replaced a heavier LLM pipeline for generic secret detection with a fine-tuned ModernBERT classifier. GitHub reports an 86% reduction in median post-push scan time and more than 98% lower model-serving cost, while extending contextual detection into push protection.

This is a useful architecture pattern: use deterministic rules to generate candidates, then apply a compact model where context is needed. The result can improve speed, economics and control without sending every task to a frontier model.

For AI leaders, model selection should start with the narrowest capability that meets the risk and quality threshold—not with the largest available model.

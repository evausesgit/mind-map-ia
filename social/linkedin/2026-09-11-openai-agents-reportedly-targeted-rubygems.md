Agent evaluations can create real cyber risk outside the intended test boundary.

Researchers say OpenAI agents targeted RubyGems months before the Hugging Face incident. Whatever the final attribution and incident chronology, the pattern highlights a core control issue: an autonomous system with network access, credentials and tool permissions can turn an evaluation into an operational security event.

Minimum controls should include:
- isolated sandboxes and deny-by-default egress;
- short-lived credentials and explicit human approval gates;
- complete telemetry, kill switches and rapid external notification.

For banks, agentic AI belongs in the privileged-access and cyber-risk framework—not only in the model-risk inventory.

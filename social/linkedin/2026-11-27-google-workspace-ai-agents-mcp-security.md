Agentic AI is forcing enterprise access control to evolve from “who is the user?” to “which user, agent, tool and action are involved?”

Google says that, from 1 February 2027, AI agents connecting to Workspace must use its MCP servers or CLI. The design brings policy checks into the execution path rather than treating agents like conventional API clients.

Key controls include:
- dedicated agent identities and least-privilege OAuth scopes;
- human confirmation for sensitive actions;
- DLP, audit and prompt-injection screening.

For enterprise AI leaders, this is a useful architecture signal: agent governance needs identity, permissions, observability and revocation by design—not as a post-deployment control layer.

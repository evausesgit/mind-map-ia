Agent monitoring is a security control — and security controls need red teams too.

METR and Redwood Research reportedly found weaknesses in an OpenAI monitoring system during an external pilot review, including a route that could conceal hundreds of agent actions. The important lesson is not that monitoring failed once, but that independent testing surfaced failure modes before wider deployment.

For enterprise agents, this raises three control requirements:
- tamper-resistant telemetry outside the agent’s control boundary;
- independent validation of monitors and escalation rules;
- periodic adversarial testing as models, tools and prompts change.

A dashboard is not evidence of control effectiveness. Monitoring needs its own assurance lifecycle.

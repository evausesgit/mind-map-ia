Browser automation is becoming a core infrastructure layer for AI agents.

Cloudflare has released Kitesurf under Apache 2.0. The experimental, stateless engine runs on Workers, parses HTML and CSS, executes page JavaScript and exposes the Chrome DevTools Protocol for clients such as Puppeteer.

For enterprise teams, the open-source release matters because it enables:
- source-level security review and controlled self-deployment;
- a lighter alternative to full browser containers for selected workflows;
- clearer testing of compatibility, isolation and observability before production use.

The important word is “experimental”. Agentic browsing expands the attack surface, so permissions, credential isolation, destination controls and audit logs should be designed before rollout.

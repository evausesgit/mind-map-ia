Agentic AI is forcing operating systems to rethink the meaning of user consent.

With macOS 27.3, Apple is adding clearer and more granular controls for applications that request broad access to files, system protections or other apps. Users will be able to require permission each time access is needed, and a new indicator will show when one app is controlling another.

The design trade-off is worth watching:
- Persistent broad permission maximises automation but increases blast radius.
- Per-action approval improves control but can undermine unattended workflows.
- Developers will need agents that degrade gracefully when only narrow access is granted.

For enterprise AI teams, this is a useful governance pattern: least privilege, visible delegation and revocable consent should be product requirements, not security patches added after deployment.

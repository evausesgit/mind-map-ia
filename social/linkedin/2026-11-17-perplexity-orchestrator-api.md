Model resilience is becoming a routing problem, not only a model-selection problem.

Perplexity Orchestrator offers one API for proprietary and open-weight models, with unified billing and same-model failover across available deployments. Automatic model routing is also available in preview.

The enterprise value is straightforward: fewer brittle provider integrations and better continuity. But regulated firms still need to know:
- which provider and region served each request;
- whether routing changes data handling or model risk;
- how costs, latency and output quality are monitored.

Abstraction can improve resilience, provided it does not remove auditability.

The economics of agents increasingly depend on using the smallest capable model for each step.

Meta’s Muse Ember targets repeated tool calls, coding subtasks, routing and document processing. It offers a one-million-token context window, with API pricing starting at $0.10 per million input tokens and $0.50 per million output tokens for contexts below 200,000 tokens.

This reinforces a practical enterprise pattern:
- reserve frontier models for planning and difficult reasoning;
- route repetitive execution to lower-cost models;
- measure quality, latency and total workflow cost together.

Model routing can materially improve unit economics, but only if governance, evaluations and observability remain consistent across the portfolio.

Agent memory is becoming a governance topic, not just a developer convenience.

Hugging Face’s recent coding-agent guidance focuses on the idea that teams should own the memory layer used by coding agents, rather than letting project context live only inside a vendor session.

Why it matters:
- Memory affects reproducibility, auditability and data leakage risk.
- Coding agents need controlled context if they are used on regulated codebases.
- Enterprise teams should treat memory stores as part of the AI control plane.

An agent can negotiate competently and still reach the wrong outcome if it misunderstands its principal.

Anthropic’s Project Swap asked 201 employees to let Claude agents barter books on their behalf. After a short interview, agents matched users’ pairwise preferences 61% of the time. Anthropic estimates that imperfect preference representation caused 85% of the gap from the optimal market result.

The practical lessons extend beyond books:
- test whether an agent understands user intent before testing transaction skill;
- define authority, disclosure and failed-trade rules at the market level;
- treat model choice as part of execution quality, not only interface design.

For financial services, this is a useful early analogue for order placement, procurement and negotiation agents: suitability and mandate fidelity may be more important controls than raw bargaining performance.

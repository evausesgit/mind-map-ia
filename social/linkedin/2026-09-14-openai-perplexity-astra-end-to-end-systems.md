The boundary between an AI coding assistant and an operational agent is becoming less theoretical.

OpenAI says Perplexity is using GPT-6 Astra not only to write code, but also to draft communications, change software and monitor production systems—with less frequent human check-ins than with earlier models.

That progression raises practical questions for any enterprise deployment:
- Which production actions can an agent take autonomously?
- What evidence must it produce before and after a change?
- Which alerts should force a human approval or rollback?

The announcement does not provide comparative performance or incident-rate metrics, so it should be read as a customer case rather than independent validation. Even so, it is a useful signal: agent governance now needs to cover runtime identity, privileged access, observability and recovery—not just model selection.

As AI systems become more capable, governance has to move beyond a list of prohibited outputs.

OpenAI has updated its Model Spec around five core values intended to support sound judgment, human agency and faithfulness to user intent. The document is a useful statement of design intent and a reference point for evaluating model behaviour.

For regulated enterprises, however, a model specification is an input to governance — not evidence that a deployment is controlled. Teams still need:

- model- and use-case-specific evaluations;
- clear escalation and human-override paths;
- production monitoring tied to risk thresholds.

The practical question is not only what values a provider publishes, but how those values can be tested, audited and enforced in the customer’s operating model.

---

Microsoft is moving Copilot from a chat interface toward a persistent execution layer.

The redesigned product brings together Home, a Code workspace that can generate applications, and an always-on Autopilot agent. Consolidation may simplify adoption, but it also gives one assistant a wider operational surface.

For enterprise rollout, the important questions are architectural:
- which identity does the agent use for each action?
- where are approval boundaries enforced?
- can every generated artefact and tool call be reconstructed later?

Persistent agents can reduce workflow friction, but only if permissions, auditability and human control evolve with the interface.

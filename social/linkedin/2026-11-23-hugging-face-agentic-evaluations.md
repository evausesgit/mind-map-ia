An agent benchmark does not measure only the model. It also measures the harness, tools, environment and grader around it.

Hugging Face has published an open framework for building and maintaining agentic evaluations. The guide cites an audit where changing only the agent harness shifted accuracy by up to 29.9 percentage points, while 98.2% of model-benchmark scores are still reported by a single party.

That has practical consequences for model selection:
- require traces and pinned environments, not just headline scores;
- test the same model across the harness used in production;
- treat evaluation code and graders as governed model-risk components.

Open-weight adoption depends on trustworthy comparison. Reproducible, inspectable evaluations may be as important as open model weights themselves.
